# Boat rocking Scenery source

Use case: stylized concept
Asset type: Capri 1535 point-and-click Scenery sprite strip Art Master
Primary request: exactly four side-view frames of the same small 1535
Mediterranean gozzo rocking gently, with no people, water, text, or watermark.
Style: warm Mediterranean pixel-art-inspired adventure illustration matching
the coastal-fortification Background.
Production ground: flat `#ff00ff` chroma background.

Generated with the built-in image generation tool. The Runtime Asset under
`src/scenes/coastal-fortification/boat-rocking.png` removes the chroma ground
and resizes the four-frame strip to 256×128 pixels using nearest-neighbour
sampling.
