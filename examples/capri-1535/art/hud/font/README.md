# Capri Pixel

The production HUD font is an original 5×7 bitmap-derived design generated by
`tools/build_hud_font.py`. The script is the editable Art Master; the generated
TTF under `src/hud/` is the Runtime Asset. It covers ASCII, the accented
Italian vowels used by Capri 1535, and the HUD symbols `–`, `‹`, `›`, `✓`, and
`×`.
