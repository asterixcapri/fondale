# 09 — Trial: a short adventure built from nothing

**What to build:** the evidence that the process works. A small adventure built
from an empty repository by following only the pipeline — story, puzzles, setup,
tickets, implementation — with no repair work smuggled in from knowledge of this
codebase.

Every point at which the pipeline stalls is a requirement nobody foresaw: a
missing document, a decision no skill asks for, an ordering that cannot be
followed, a generation that will not converge. The output of this ticket is the
finished small game plus the list of those findings.

This is manual validation. It must never be reported as a passing test.
