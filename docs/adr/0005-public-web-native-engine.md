# Motore web-native pubblico distribuito come pacchetto npm

Fondale sarà pubblicato con licenza MIT come `@asterixcapri/fondale` e potrà
essere usato anche da progetti di gioco in repository indipendenti. La prima
versione stabile è rivolta a sviluppatori TypeScript e ai browser desktop
moderni; authoring no-code, plugin generici, dispositivi mobili e wrapper
desktop non fanno parte del contratto 1.0, così la stabilità pubblica riguarda
soltanto capacità già validate da un gioco reale.
